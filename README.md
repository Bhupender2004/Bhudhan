## 📋 Overview

**BhuDhan** (भूधन — meaning "Wealth of the Earth") is a full-stack, AI-powered agricultural platform built to empower Indian farmers with modern technology. From real-time weather intelligence and crop disease detection to a digital marketplace and expert consultations — BhuDhan brings the digital revolution to India's farmlands.

> _"Transforming agriculture, one farmer at a time."_

### 🎯 Problem Statement

Indian farmers face critical challenges: unpredictable weather, crop diseases, unfair market prices, and limited access to expert advice. BhuDhan bridges this gap by providing an all-in-one platform that leverages AI, real-time data, and community support.

### 💡 Solution

A mobile-first, multilingual platform that provides:
- 🤖 **AI-powered crop analysis** — Detect diseases, predict yields, analyze soil
- 🌦️ **Real-time weather intelligence** — Location-based forecasts and alerts
- 🛒 **Digital marketplace** — Buy/sell seeds, fertilizers, equipment directly
- 👨‍🌾 **Expert connect** — Chat with agricultural specialists
- 📰 **Knowledge hub** — News, government schemes, farming guides

## 🚀 Getting Started

### Prerequisites

| Requirement | Version |
|------------|---------|
| Node.js | 18+ |
| npm | 9+ |
| MongoDB Atlas | Free tier or above |
| Clerk Account | Free tier |
| OpenAI API Key | Required for AI features |
| OpenWeatherMap Key | Required for weather |

### ⚙️ Installation

1. **Clone the repository**

```bash
git clone https://github.com/Bhupender2004/Bhudhan.git
cd Bhudhan
```

2. **Install dependencies**

```bash
npm install
```

3. **Configure environment variables**

Create a `.env.local` file in the root directory with the following keys:

```env
# ─── Clerk Authentication ──────────────────────
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
CLERK_SECRET_KEY=sk_test_...
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up
NEXT_PUBLIC_CLERK_AFTER_SIGN_IN_URL=/dashboard
NEXT_PUBLIC_CLERK_AFTER_SIGN_UP_URL=/dashboard

# ─── MongoDB ───────────────────────────────────
MONGODB_URI=mongodb+srv://...

# ─── Firebase ──────────────────────────────────
NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...

# ─── OpenAI ────────────────────────────────────
OPENAI_API_KEY=sk-...

# ─── Weather ───────────────────────────────────
NEXT_PUBLIC_OPENWEATHERMAP_API_KEY=...

# ─── Google Translate ──────────────────────────
GOOGLE_TRANSLATE_API_KEY=...
```

4. **Run the development server**

```bash
npm run dev
```

5. **Open your browser**

Navigate to [http://localhost:3000](http://localhost:3000) to see BhuDhan in action! 🎉

### 📦 Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server with Turbopack ⚡ |
| `npm run build` | Create optimized production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint checks |
| `npm run generate-translations` | Generate translation files |
